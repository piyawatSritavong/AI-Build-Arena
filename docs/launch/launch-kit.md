## First content clip (45–60 s, vertical)
**Hook (0–3 s):** on-screen text "ตามเทรนด์ AI ไม่ทัน?" + a screen full of MCP logos.
**Turn (3–10 s):** "บางทีคุณไม่ได้ตกเทรนด์ แค่แบกของเยอะเกิน" + pixel character visibly weighed down.
**Demo 1 (10–25 s):** Trend Check: tick tools, show Meta Sync %, highlight one 🔥 Hype and one 🍂 Fading item.
**Demo 2 (25–40 s):** paste a real config into Loadout Doctor and show "2 tools cover memory" plus the token estimate. Blur any real paths.
**Payoff (40–55 s):** Arena: Claude Code solves the baht-text challenge live, then the card with its aura appears.
**CTA (55–60 s):** "เช็กของคุณใน 60 วินาที ลิงก์ในโปรไฟล์". End card = the OG share image.

Shot list: screen recordings at 1080×1920, cursor highlight on, browser zoom 125%, dark mode. Record Trend Check, Doctor (with a sample config), and an Arena run in Claude Code.
